# Police Control Room

A React + Vite application for police operations, including challan handling, camera monitoring, alerts, and a mobile-friendly Android wrapper via Capacitor.

## Tech Stack

- React 18
- Vite
- Capacitor Android
- Supabase
- React Router

## Getting Started

1. Install dependencies:
   npm install
2. Start the app in development mode:
   npm run dev
3. Build for production:
   npm run build

## Environment Variables

Copy `.env.example` to `.env` and update any required values before running the app.

## Notes

This project includes helper scripts for database checks and data seeding, but those are not part of the app runtime.
